# CoSpace 项目展示与 GitHub 发布说明

## 项目简介

CoSpace 是面向小团队的协作工作台，将项目、任务、阻塞、成果与验收关联起来。当前版本是本地全栈 MVP，可运行从任务创建到成果验收和资产沉淀的流程。

## 可以展示的设计与实现

- 围绕实际协作动作组织团队总览、我的工作、项目与资产中心。
- 明确负责人和验收人的职责，提交后进入待验收，通过后才计入完成。
- 保留历次提交和退回意见，通过事务和任务版本检查避免重复写入与覆盖更新。
- 协助人提出解决方案，由任务负责人确认解除阻塞。
- 导出含目标、任务版本、成果和未决问题的交接上下文。
- 通过本地 PostgreSQL 引擎持久化，并为独立 PostgreSQL 连接提供适配。

## 作品集描述示例

设计并推进 CoSpace 团队协作工作台 MVP，将任务背景、成果提交、独立验收、阻塞确认和资产沉淀组织为完整流程。使用 Codex 辅助完成 Next.js 与 TypeScript 实现，通过集成测试、HTTP 流程和浏览器操作检查验证核心规则。当前支持本地运行，尚未部署公网或接入 Agent 自动执行。

使用时请依据实际工作修改个人职责。能清楚解释产品取舍、数据关系、权限、验证结果和局限，比夸大开发范围更有说服力。尚无真实团队长期使用数据，不宜声称已提高团队效率或实现商业化。

## 推荐公开范围

适合提交：src、tests、scripts、docs、design 中已确认可公开的文档与演示图，以及 README、package.json、package-lock.json、TypeScript 和 Next.js 配置、.gitignore、.env.example。

不要提交：.env.local 等真实环境配置、.data 中的数据库与会话、node_modules、.next、日志、缓存和 .work 中的文档制作中间文件。现有忽略规则已覆盖这些目录和文件；使用文件夹拖拽上传时仍需手动避免上传。

代码中的 cospace-local-2026 是明确公开的本地演示密码。它可以用于克隆后的本地演示，不能作为真实线上工作区的密码。数据库本身不得随源码公开。

当前目录尚未初始化为 Git 仓库，也没有连接 GitHub 远程地址。本次仅准备说明文件，没有执行提交、推送或对外发布。

## 发布前补充

1. 核对待提交文件，不包含真实团队资料、真实账号凭证或私有成果链接。
2. 阅读源码并能说明关键权限和状态规则；如实注明 AI 辅助开发。
3. 放入一段从创建任务到退回重提、通过验收的短演示，使用虚构数据。
4. 按自己的分享意图选择许可证后再加入 LICENSE；本次没有代选许可证。
5. 仓库展示与线上部署分开处理。GitHub 仓库本身不会运行此项目的后端与数据库。
